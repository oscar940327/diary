# 討論紀錄索引

[DISCUSSION.md](../../DISCUSSION.md) 只放目前方向、未決問題與下一步。歷史紀錄放在這裡，需要理解決策過程時再閱讀。

## 保存方式

- 每次規劃對話結束，補一段有日期的摘要；即使沒有決定，也記下正在討論什麼。
- 每段以三到六個簡短要點或短段落為原則，分清楚「已確認」與「討論中」。不抄逐字稿、不重貼整份現況。
- 使用 `YYYY-MM.md` 按月保存。若加入新摘要會超過約 200 行，改開 `YYYY-MM-part-02.md`，之後依序編號。
- 新月份或新分冊加到下方索引。每份歷史文件連回根目錄的現況摘要。
- 歷史紀錄描述當時的理解；後來改變方向時新增紀錄，不回頭抹去原來的討論。
- 目前技術選擇以白話記在 [技術文件](../tech-stack.md)，詳細行為放進規格與 Tickets；這裡保留簡短結論與連結即可。
- Agent 開始工作時先讀現況摘要和相關規格，不必每次重讀全部歷史。
