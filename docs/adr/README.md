# Architecture decisions

For the active rebuild on `main`, the accepted technology choices are written
in plain language in [docs/tech-stack.md](../tech-stack.md).
ADR 0018 remains as a pointer for older discussion links.

ADRs 0001-0017 describe v1. They remain useful design history, but their
website, Supabase, Azure, authentication, and release assumptions are not
automatic v2 requirements. Reused product rules belong explicitly in the
v2 specification; new v2 decisions continue the numbering after 0018.
